
## TDA (type de donné abstrait)

- doit disposer de ensemble_est_plein() pour savoir si l'on peut encore ajouter un élément
- differente méthode d'implémentation en fonction des language

exemple de nouveau type : 
```
Type Toto
	a : entier
	b,c : Reel
	t : tabR
FinType
```

## TDA séquentiels


### File (Queue)

- FIFO (First In, First Out)

### Pile (Stack)

- LFIO (Last in, First out)

### Liste (list)

- parcour sequentiell (debut a la fin )
