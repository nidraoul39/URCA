Révision

Il est important de bien se préparer pour le stron TP Test. Pour cela, il faut revoir les différents TP, bien regarder si on est capable de répondre correctement aux questions posées en vérifiant dans les archives "Résultats obtenus" le code correspondant.
N'oubliez pas de lire les consignes du TP Test. En l'occurrence, notez que vous avez 55 minutes pour faire le sujet ET déposer ! Aucun travail ne sera accepté passé ce délai.
